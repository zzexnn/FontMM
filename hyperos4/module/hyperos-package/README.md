# FontMM HyperOS 4 upgrade

An unofficial compatibility patch for Xiaomi HyperOS 4 / Android 17; original FontMM by Yule (YuleBest/FontMM, GPL-3.0).

This ZIP is **not a standalone installer**. It requires the existing original FontMM v26.8.0-beta.10 installed with a Chinese font already selected. Do not uninstall the original module before applying this upgrade. The upgrade keeps the original WebUI and fonts, adds HyperOS font overlays, and avoids overriding the ColorOS XML on HyperOS.

After installation: reboot, use the existing FontMM WebUI to select and apply fonts, then reboot again. Unsupported devices / versions may fail. User feedback confirmed startup, font replacement in Settings, and weight previews on one HyperOS 4 phone, not universal compatibility.
